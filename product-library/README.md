# Levin Product Library Prototype

这是一个使用真实SKU与产品图片制作的内部产品库交互原型，当前用于验证：

- SKU、名称、材质和标签搜索
- 品类筛选及卡片/列表视图
- 产品详情、图片素材与备底报价入口
- 加入选品集并准备创建 Catalog
- 桌面端和移动端布局

## 本地预览

在本目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173`。

当前版本为前端原型，产品数据写在 `app.js` 中；下一阶段应将其替换为自动扫描文件库生成的数据库/API数据。
